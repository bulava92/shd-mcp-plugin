# Controller observability widget

This artifact is served by the SHD MCP backend as `ui://shd/controller-observability/v1.html`.

It is a standalone parameterized MCP App. The same UI contract renders controller device inventory, live state, server-computed state statistics, history, series comparison, expert settings, lightweight topology, telemetry health and source audit modes. A selected device profile is loaded on demand through the profile tool.
